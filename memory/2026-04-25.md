# 2026-04-25

## Phân tích dự án VClaw

- VClaw là app vận hành bán hàng local-first cho SMB/hộ kinh doanh Việt Nam, dùng `vclaw-ui` làm Business Dashboard Next.js và `core/openclaw` làm runtime/gateway/agent framework.
- Source-of-truth tài liệu chia 2 vùng: `vclaw-ui/docs/` là public docs serve qua `/docs`, còn `docs/` ở root là private/internal cho packaging, tích hợp, Gateway, OpenClaw và Zalo.
- `vclaw-ui` hiện dùng Next.js 16 App Router, React 19, `next-intl`, Prisma + SQLite, Tailwind CSS, shadcn-style primitives và Vitest. `next.config.ts` đang dùng `output: "standalone"`, không phải static export, để giữ API routes, Server Actions, Prisma và proxy Gateway cho bản desktop.
- Data model chính nằm trong `vclaw-ui/prisma/schema.prisma`: Customer, Order, Payment, Booking, Task, Product, ShopSettings, IntegrationAccount/Group, ChannelConnection, Conversation/ConversationMessage, AgentToolLog, AutomationJob.
- Admin surface hiện có dashboard, inbox, customers, orders, payments, bookings, products, shipping, automation, reports, settings, guide và Zalo Personal admin. Logic được tách theo domain trong `vclaw-ui/lib/*`.
- OpenClaw Gateway là control plane chính qua WebSocket JSON frames (`connect`, `req`/`res`, `event`). Browser client ở `lib/gateway/client.ts`, server-side RPC ở `lib/openclaw/gateway-ws-rpc-server.ts`, REST proxy ở `app/api/gateway/[...path]/route.ts`.
- Zalo Personal (`zalouser`) được nối qua Gateway WS (`web.login.start`, `web.login.wait`, `channels.status/logout`, `sessions.*`, `send`, `directory.*`) với fallback/server actions trong `lib/zalouser/*`.
- Packaging hiện là macOS `.pkg`/Electron shell: `scripts/package-vclaw.sh` build Next standalone, stage static assets, pack local `core/openclaw` và `core/extensions/zalouser`, nhúng config mặc định, tạo `VClaw.app` và installer.
- Có lệch tài liệu cần nhớ: `KNOWLEDGE_INDEX.md`/README nhắc `docs/README.md` nhưng file chưa tồn tại; một số docs cũ còn nhắc static export hoặc path cũ `lib/gateway-client.ts`, trong khi code thực tế đã chuyển sang `lib/gateway/client.ts` và standalone desktop runtime.
