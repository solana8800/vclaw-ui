# VClaw Desktop Installation and User Guide (For Users)

Welcome to **VClaw** - The smart Agentic Assistant for your business. This guide will help you install and start using VClaw in just a few minutes.

---

## 1. Installation on macOS

VClaw is optimized for macOS (Intel and Apple Silicon).

### Step 1: Download and Install
1. Download the `VClaw-Installer.dmg` file from the official website or GitHub.
2. Open the downloaded `.dmg` file.
3. Drag the **VClaw** icon into the **Applications** folder.

### Step 2: System Permissions
1. When opening the app for the first time, if macOS displays a warning about an unverified developer, go to **System Settings > Privacy & Security** and select **Open Anyway**.
2. VClaw will request the following permissions:
   - **Notifications**: To send alerts when the Agent completes a task.
   - **Accessibility**: (Optional) So the Agent can interact with other applications.

---

## 2. Initial Setup (Onboarding)

After launching, VClaw will display the **Setup Wizard**:

### Step 1: Connect AI (Gemini)
VClaw uses the brain from Google Gemini.
1. Visit [Google AI Studio](https://aistudio.google.com/) to get your API Key.
2. Paste the Key into the configuration box in VClaw.

### Step 2: Connect Communication Channel (Telegram)
So you can command the AI remotely via your phone:
1. Create a new Telegram Bot via `@BotFather`.
2. Get the **Bot Token** and enter it into VClaw.
3. Send any message to your Bot to activate the connection.

---

## 3. Basic Usage

### Option 1: Using the Dashboard Interface
- Open the Dashboard by clicking the VClaw icon on the Menu Bar.
- Here you can view:
  - **Task Inbox**: Tasks the AI is performing or waiting for your approval.
  - **Reports**: Track revenue and work progress.

### Option 2: Commanding via Telegram (Remote Control)
You don't need to open your computer to work:
- Message the Bot: *"How many new orders today?"*
- Message the Bot: *"Write an email to customer A about..."*
- The AI will automatically execute and send the results back to your Telegram.

---

## 4. Support and Updates

- **Automatic Updates**: When a new version is available, VClaw will display a notification. Select **Install Update** to receive the latest AI features.
- **Help**: Message `help` in the Telegram Bot or click the **Support** button in the app.

---

> [!NOTE]
> VClaw secures all your data locally. The AI only accesses the information you allow to perform the requested tasks.
