# P1 Backlog

P1 là việc quan trọng sau khi P0 đủ chạy cho pilot.

## Shipping

- [ ] Kiểm tra cấu hình GHN/GHTK và fallback local quote.
- [ ] Gắn shipping estimate vào order.
- [ ] Chuẩn hóa address từ text hội thoại thành shipping note.

## Product và customer

- [ ] Product manager tạo/sửa/archive ổn định.
- [ ] Customer profile hiển thị hội thoại, đơn, thanh toán và booking liên quan.
- [ ] Import/export SKU Shopee ở mức file CSV hoặc copyable table.

## Automation guardrail

- [ ] Automation queue có trạng thái approval rõ.
- [ ] Draft outbound không tự gửi khi chưa được duyệt.
- [ ] Log tool/action quan trọng vào `AgentToolLog` hoặc activity tương đương.

## Packaging

- [ ] Chạy `bash scripts/package-vclaw.sh` trên môi trường sạch.
- [ ] Kiểm tra installer `.pkg` cài được app vào `/Applications`.
- [ ] Kiểm tra postinstall cài OpenClaw runtime user-space.
