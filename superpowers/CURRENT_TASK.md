## Khi nào dùng file này

Codex phải đọc file này trước khi chọn task mới từ backlog. Nếu `Status` khác `Idle`, tiếp tục hoặc xử lý blocker của task hiện tại trước.

## Trạng thái hợp lệ

- `Idle`: không có task đang làm dở.
- `In Progress`: đang thực hiện task.
- `Blocked`: task bị chặn, cần thông tin/môi trường/quyền.
- `Needs Review`: đã làm xong code/docs nhưng cần người dùng review hoặc live verification.
