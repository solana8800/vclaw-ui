Cài đặt VClaw

Sau khi chép ứng dụng vào Applications, trình cài sẽ chạy thêm các bước (có thể 5–15 phút tùy mạng):

  • Chuẩn bị ~/.openclaw và cài OpenClaw CLI (bản tích hợp sẵn từ gói openclaw-bundled.tgz)
  • Mở Terminal chạy vclaw-zero.sh — tại đó bạn sẽ mở Chrome, onboard webauth, rồi khởi động gateway (port 3001; không tự chạy gateway khi cài pkg)

Zero Token (cuối cài đặt, trước khi mở VClaw): trình cài thường tự mở Terminal chạy bash /Applications/VClaw.app/Contents/Resources/vclaw-zero.sh. Nếu không thấy cửa sổ Terminal, hãy chạy lệnh đó thủ công. Script mở Chrome với cùng profile shell VClaw; đóng VClaw nếu đã mở nhầm, rồi trong Chrome hãy đăng nhập Google/Gmail chung cho các trang bot AI (ChatGPT, Claude, …) cần tài khoản Google, làm theo bước openclaw onboard webauth. Sau đó mới mở VClaw từ Applications.

Xem tiến trình chi tiết: trong ứng dụng Installer, mở menu Cửa sổ (Window) → Nhật ký cài đặt (Installer Log), chọn mức Hiển thị tất cả nhật ký (Show All Logs). Bạn sẽ thấy các dòng bắt đầu bằng [VClaw] theo thời gian thực.

Ngoài ra, macOS có thể hiển thị thông báo (Notification) từng bước lớn (nếu đã bật thông báo cho Installer).
